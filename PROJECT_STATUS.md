### Evidence-Based & Neurodivergent-Led ✅

All content is grounded in:

**Neurodivergent-Led Research:**
- ✅ AASPIRE (Academic Autism Spectrum Partnership in Research and Education)
- ✅ Autistic Women & Nonbinary Network (AWN) - Transformative Justice frameworks
- ✅ 988 Lifeline - Neurodivergent crisis resources
- ✅ NEST Study (2024) - Neurodivergent peer support research
- ✅ SAMHSA 2024 - Peer support across crisis continuum

**Frameworks Used:**
- ✅ Transformative & Restorative Justice (not punitive approaches)
- ✅ Disability Justice principles ("Nothing About Us Without Us")
- ✅ Social Model of Disability
- ✅ Universal Design for Learning (UDL)
- ✅ Community-Based Participatory Research (CBPR)
- ✅ Neurodiversity-affirming intervention models

**Key Research Findings Integrated:**
- Wellbeing depends on acceptance and support, not symptom reduction
- Autistic burnout as chronic stress + mismatch of expectations
- Peer support reduces suicidality
- Masking increases burnout
- Explicit communication reduces misunderstandings

## How to Build the GitBook

### Option 1: GitBook.com (Easiest)
1. Create account at gitbook.com
2. Import this directory as a new book
3. GitBook will read SUMMARY.md and build navigation
4. Publish!

### Option 2: GitBook CLI (More Control)
```bash
# Install GitBook CLI
npm install -g gitbook-cli

# Navigate to this directory
cd /Users/annhoward/src/multiverse_admin_handbook

# Initialize and serve locally
gitbook init
gitbook serve

# Build static HTML
gitbook build
```

### Option 3: GitHub Pages
- Push to GitHub repository
- Enable GitHub Pages
- GitBook will auto-build from SUMMARY.md
